# Чи буде дощ завтра? — Streamlit

**[Відкрити застосунок](https://lupandin-weather-rain.streamlit.app/)** · [GitHub-репозиторій](https://github.com/Violinist33/weather-rain-streamlit)

Домашнє завдання з деплойменту моделі машинного навчання.
Додаток приймає погодні спостереження з австралійської метеостанції та
прогнозує `RainTomorrow`: `Yes` або `No`. Показує ймовірність дощу та
ймовірність прогнозованого класу окремо.

## Запуск

Потрібен Python **3.12**. Усі команди виконуються в папці цього проєкту.

```bash
python -m venv .venv
source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Навчена модель уже включена. CSV та повторне навчання для запуску не потрібні.
Натисніть «Заповнити приклад», а потім «Отримати прогноз».
Приклад узято з weatherAUS: Sydney, 20.10.2010; це не поточна погода.
Інші показники доступні у вкладках «Вологість і небо» та «Вітер».

## Потік даних

1. Форма збирає один рядок із 21 ознаки.
2. Перевіряються метеостанція, наявність числових спостережень та порядок мінімальної/максимальної температури.
3. `SimpleImputer` замінює числові пропуски середніми з навчальної вибірки.
4. `MinMaxScaler` масштабує числові ознаки з параметрами, отриманими під час навчання.
5. `OneHotEncoder` кодує категорії. Пропущені категорії передаються як `NaN`; якщо така категорія була в навчанні, вона має окремий стовпець. Незнайомі категорії обробляються через `handle_unknown="ignore"`.
6. Числові й закодовані ознаки з'єднуються в незмінному порядку.
7. `RandomForestClassifier.predict` дає клас, `predict_proba` — ймовірності. Ймовірність `Yes` знаходиться через `model.classes_`.

На етапі прогнозу викликається тільки `transform`, без `fit`.
Модель завантажується один раз через `st.cache_resource`.
Масштабування залишене для відповідності завданню; для дерев воно зазвичай не є необхідним.

## Модель і якість

У наданому лекційному `aussie_rain.joblib` виявлено **LogisticRegression**, а завдання
вимагає **Random Forest**. Оригінал збережено як `models/aussie_rain_original.joblib`.
Додаток використовує новий `models/aussie_rain.joblib`: Random Forest та всі
обробники, навчені заново лише на навчальній частині weatherAUS.

- Дані: 145 460 рядків; вилучено 3 267 рядків без цільової мітки.
- Навчання: 2007–2014, 98 988 рядків.
- Валідація: 2015, 17 231 рядок.
- Тест: 2016–2017, 25 974 рядки.
- 150 дерев, максимальна глибина 16, мінімум 5 спостережень у листку, `random_state=42`.
- 21 вхідна ознака перетворюється на 119 числових ознак.
- `Date`, `RainTomorrow` та `RISK_MM` (якщо є в CSV) не подаються моделі.
- Параметри фіксовані до оцінювання; поріг відповідає `predict` для двох класів.

| Метрика | Валідація | Тест |
|---|---:|---:|
| Accuracy | 0.8521 | 0.8400 |
| Precision для Yes | 0.7909 | 0.7661 |
| Recall для Yes | 0.4095 | 0.4331 |
| F1 для Yes | 0.5396 | 0.5533 |
| ROC AUC | 0.8735 | 0.8614 |
| Accuracy постійного прогнозу No | 0.7883 | 0.7711 |

На тесті модель краща за постійний прогноз «без дощу», проте виявляє лише
43.3% дощових спостережень. Тому accuracy 84% не означає, що модель добре
знаходить усі дощі. Ймовірності — оцінки моделі без окремого калібрування.
Це навчальний застосунок, а не підключення до поточного метеопрогнозу.
Повні метрики та матриці помилок збережені в `training_report.json`.

## Відтворення навчання

Джерело: [Rain in Australia / weatherAUS](https://www.kaggle.com/datasets/jsphyg/weather-dataset-rattle-package).
Завантажте й розпакуйте `weatherAUS.csv`, потім виконайте:

```bash
python train.py --data /path/to/weatherAUS.csv
python -m unittest -v
```

Команда навчання перезаписує лише робочу модель та звіт; оригінальна модель
залишається окремим файлом. SHA-256 використаного CSV записаний у звіті.
Модель стиснута `joblib.dump(..., compress=("zlib", 3))`, розмір приблизно 13 МБ.
Версію scikit-learn зафіксовано, оскільки joblib-моделі залежать від версії бібліотеки.

## Публікація у Streamlit Community Cloud

1. Завантажте в публічний GitHub-репозиторій вміст цієї папки, включно з `models/` та `.streamlit/config.toml`.
2. На [share.streamlit.io](https://share.streamlit.io/) оберіть **Create app** → розгортання з GitHub.
3. Вкажіть репозиторій, гілку `main` і головний файл `app.py`.
4. У **Advanced settings** оберіть Python **3.12**. Натисніть **Deploy**.
5. Відкрийте отриману адресу `.streamlit.app`, перевірте приклад та прогноз.
6. Для здачі надішліть посилання на застосунок і репозиторій.

Якщо папку додано всередину іншого репозиторію, вкажіть шлях до її `app.py`,
наприклад `streamlit_rain/app.py`, замість кореневого `app.py`.
